Lesson 11: Go Orchestration And Tests

Skill: read Argus Go commands as pipeline orchestration, not classic web-server code.

The Go code mostly owns command-line contracts, config loading, validation, orchestration, JSON outputs, and testable wrappers. Heavy table work is often delegated to DuckDB through Python adapter scripts.

The One Thing

When you open a command under cmd/, look for the pipeline contract: required flags, default config paths, artifact paths, validation before work, adapter call, checkpoint/write behavior, and JSON result shape.

Repo anchors: cmd/scan-candidates/main.go, internal/candidate/scanner.go, internal/relevance/scorer.go, internal/database/admin.go.

Testing Pattern

Tests often build small fixtures, run the Go wrapper or adapter, assert JSON/counts/files, then rerun to verify idempotency or failure behavior. This is closer to integration testing than isolated handler testing.
