Lesson 10: Query, Ask, Evidence

Skill: explain how Argus keeps analyst and LLM answers evidence-backed.

The query layer is intentionally guarded. Users and LLMs should not free-roam raw storage; they query curated views and return evidence rows that can be inspected.

The One Thing

Argus answers should be traceable. A useful answer is not "the model thinks visas are painful." A useful answer is "these recurring visa pain points appear in retained documents, with source URLs, snippets, and run metadata."

go run ./cmd/query \
  --query-name signal_summary \
  --signal-type pain_point \
  --limit 10

Repo anchors: cmd/query, cmd/ask, docs/runbooks/phase-6-query-layer.md, docs/runbooks/phase-6-llm-ask.md.

LLM Boundary

The LLM plans retrieval and synthesizes from retrieved rows. The durable guarantee still comes from local data, guarded query names, evidence document IDs, and saved ask runs.
