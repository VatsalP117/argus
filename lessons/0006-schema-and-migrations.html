Lesson 6: Schema And Migrations

Skill: read the durable schema as a product model, not just a set of tables.

The schema tells you what the product believes is worth preserving. Argus does not only store documents; it stores relevance decisions, signals, entities, themes, opportunities, manifests, batches, reconciliation, saved research, and ask runs.

The One Thing

The core table is documents. Most research tables hang off document_id. Operational tables explain how those rows arrived and whether they can be trusted. Migration files in sql/migrations/ evolve this durable contract.

Repo anchors: sql/migrations/001_initial_durable_schema.sql, 002_candidate_batch_lifecycle.sql, 003_scored_staging_metadata.sql, internal/database/admin.go.

Migration Rule Of Thumb

Applied migrations are historical evidence. If a migration has already been applied, changing its text should be treated as suspicious because it rewrites what the system claims happened.
