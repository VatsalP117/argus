Lesson 7: Validation And Reconciliation

Skill: explain the row-count equations that protect Argus from losing data silently.

Validation asks "does this data satisfy the rules?" Reconciliation asks "can every row be accounted for?" Argus needs both before it trusts a batch or deletes staging.

The One Thing

rows_seen = rows_rejected_early + rows_staged
rows_staged = rows_retained + rows_rejected_late + rows_quarantined

If either equation fails, Argus does not know where some rows went. That is a stop sign.

Fullstack Bridge

Unit tests prove code behavior. Data validation proves data state. Reconciliation is the accounting layer between the two.
