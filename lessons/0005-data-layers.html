Lesson 5: Data Layers

Skill: name each Argus data layer and what it is responsible for.

Data engineering systems often separate layers so each stage has a clear contract. Argus uses layers to avoid mixing recoverable source data, temporary processing files, cleaned analytical text, curated research outputs, and durable product state.

The One Thing

Remote archive: recoverable upstream Reddit Parquet.
Temporary staging: bounded candidate and score Parquet that can be deleted after validation.
Clean layer: normalized text, flags, dedupe, and provenance.
Marts: curated views/tables shaped for research questions.
Durable corpus: data/argus.duckdb, the local product database for retained evidence and metadata.
