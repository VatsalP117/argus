Argus Pipeline Safety Checklist

Use this before deleting staging, widening ingestion, or trusting a research result.

  1. Source pinned: archive repo, revision, source path, and source identity are recorded.
  2. Manifest stable: the manifest ID and checksum match the work being run.
  3. Config versioned: candidate, relevance, storage, and pipeline configs are known and checksummed where needed.
  4. Checkpoint valid: retries reuse only matching input, config hash, output path, and output checksum.
  5. Original text preserved: retained rows keep the source text and a direct source URL.
  6. Rows reconcile: source and staging equations both evaluate true.
  7. Durable commit validated: retained documents, relevance rows, signals, and entities match expected counts.
  8. Quality gates pass: relevance precision/recall and false-positive checks are acceptable for the next scope.
  9. Cleanup audited: every deleted staging file has a cleanup event and checksum verification.
  10. Stop if unsure: if any artifact cannot explain where data came from or where rows went, do not widen scope.
