Argus Pipeline Map

Use this as the one-page route map. The important shape is not "run scripts in order"; it is "move from recoverable source to trusted evidence while preserving proof."

Phase 0

Bootstrap

Install local requirements, check disk capacity, prepare DuckDB and Python support. Guard: do not start broad processing if local capacity is unsafe.

Phase 1

Archive Validation

Confirm the remote archive is readable and has the expected Reddit fields. Artifact: discovery SQL and archive validation notes.

Phase 2

Manifest And Ingest

Build pinned manifests for bounded source shards, then ingest only scoped data. Artifact: manifest plus checkpoints.

Phase 3

Clean Transform

Normalize text, preserve original text, deduplicate, flag removed/deleted/bot-like rows, and keep provenance.

Phase 4

Signal Enrichment

Extract deterministic research signals and entities. Artifact: signal/entity outputs and validation checks.

Phase 5

Evidence Export

Package results for analyst review with source IDs, source URLs, and evidence snippets.

Phase 6

Query And Ask

Expose guarded read-only query workflows and evidence-backed LLM answers over curated local views.

Phase 7

Broad Candidate Scan

Scan pinned shards with high-recall rules. Output is temporary candidate Parquet.

Phase 8

Score, Commit, Cleanup

Score candidates, evaluate quality, commit retained evidence transactionally, reconcile counts, and only then delete staging. Quality gates can stop the pipeline.
