DuckDB And SQL Cheatsheet For Argus

DuckDB is the local analytical engine Argus uses to scan Parquet, run checks, build outputs, and maintain the durable research corpus.

Read Parquet

SELECT *
FROM read_parquet('data/tmp/candidates/*.parquet')
LIMIT 10;

In Argus, Parquet is both a remote archive format and a temporary staging format.

Inspect Shape

DESCRIBE SELECT *
FROM read_parquet('data/tmp/candidates/example.parquet');

Use this before writing assumptions into SQL or Go structs.

Data Quality Counts

SELECT
  count(*) AS rows_total,
  count(*) FILTER (WHERE clean_text = '') AS empty_clean_text,
  count(*) FILTER (WHERE source_url IS NULL) AS missing_source_url
FROM documents;

Many Argus checks are this idea scaled up: count, group, prove that bad states are absent or bounded.

Reconciliation Equation

SELECT
  rows_seen = rows_rejected_early + rows_staged AS source_equation_valid,
  rows_staged = rows_retained + rows_rejected_late + rows_quarantined AS staging_equation_valid
FROM batch_reconciliation;

This is the heartbeat of safe cleanup. If the rows do not account for themselves, staging should not be deleted.
